# 动物园 Galgame 剧本

本目录是故事设计与完整文字剧本；`reference/`存放原始资料，`docs/`继续存放程序文档。正式游戏数据位于`data/story.json`，由`tools/build_story.py`编译本稿、完整规则与分支控制生成。图片、音乐、物品与成就已接入；制作后的补充与验证记录见`docs/制作验收.md`。

推荐阅读顺序：

1. [主线设计](主线设计.md)：双线框架、时间轴、原文与改编边界。
2. [人物设定](人物设定.md)：固定人设、配角与音画风格。
3. [分支与状态](分支与状态.md)：操作窗口、变量、转场与结局入口。
4. [游客线](游客线.md)：完整场景、台词、动作与演出指示。
5. [员工线](员工线.md)：另一视角的完整场景。
6. [结局集](结局集.md)：两个真结局、生还分支及坏结局正文。
7. [规则核对](规则核对.md)：逐项核对与无法由原文保证的部分。

`[ ]`写环境、动作、画面和音频提示；`（ ）`写当前视角心理；`姓名：`写对白；`＜ ＞`写游戏进度、操作、条件、资料显示及跳转。制作提示不作为角色能看到的信息。

每份守则整节引用`reference/动物园怪谈正文.md`，不在本目录再复制一份可能漂移的原文。场景里的完整显示指令必须在制作时载入对应整节，包括隐藏文字和笔迹说明。原文共九份，QA和解析不作为园内道具。

本目录保留创作稿供对照；游戏中的新增商店、物品反馈和结局BX1见`tools/build_story.py`。最终跳转、状态和演出以正式JSON及`data/logic.py`为准。角色对白使用可关闭的短音提示，没有真人配音。
