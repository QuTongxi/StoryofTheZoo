# 制作与验收记录

2026-10-22，版本 1.0.0。本文件包含制作层面的剧情信息，首次游玩请先看根目录 README。

## 已落地内容

- `data/story.json`：53 章、1176 个节点，游客与员工两条路线，23 个结局；`data/logic.py` 处理物品、条件与结算。
- 15 种物品定义，购买、余额、主动使用、地图误操作反馈、食品外观变化、玩偶收存和离园检查。
- 35 项成就，跨周目资料馆、结局 CG 画廊；9 份完整规则文档按到达地点或主动调查解锁。
- 97 张最终插画：38 张背景、20 张人物及差分、12 张物品、4 张开场／路线／事件图、23 张逐结局 CG。人物母版也作为后续作画参考保留。背景覆盖白天、黄昏、夜间、黎明和异常状态。
- 5 首授权背景音乐、19 个项目合成 WAV 音效、2 个 Kenney 界面音效。角色使用低音量逐字短音，可关闭；没有真人配音。
- GUI 与 CLI 共用判定、存档及回放。批量 CLI 接受显式选择和物品操作，不修改角色状态来伪造通关。

## 叙事与画面核对

使用项目的 `audit-impossible-knowledge` 方法检查知识来源、可选探索与跨视角信息。保留原始规则文件；制作稿中的元说明不作为角色对白。

- 地图虚线部分与门票分别处理；拥有地图不等于完成撕取与握持。
- 游客入馆与最早离馆时间明确，看到海洋馆不自动锁死返程。保安的当班时间与红衣换班时间分开。
- 蓝衣临时接红衣工作是用户指定的改编，不把它写成原文保证的安全晋升机制。默默保护熟人是角色的选择，不捏造“绝对不能认出熟人”的规则。
- 正常四头白狮与异常第五头使用不同图片。危险 CG 修正了人物母版混用、白天误画为夜晚、把无形压力画成实体施害者等问题。
- 表白演出先用暗室背景，人物坐近后才切事件 CG；夜间差分不会因通用害羞对白误换回白天服装。
- 三张纸条均可跳过。资料馆保存玩家收藏，不把跨周目信息注入当前角色；拒绝顶班的结局不声称员工已经知道同学在馆内。
